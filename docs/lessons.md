# Lessons

- 2026-09-14: Integration tests run against a retained local database. Use unique names for constrained fixture rows, and compare error counts within the actual hourly aggregation bucket. A fixed season name and an old error bucket caused repeat runs to fail even though the backend and migrations were current; resetting the database would hide those test defects.
- 2026-09-14: Event-copy tests must save the inferred source format unchanged and compare persisted tee groups. Switching to individual gross before saving hid the format-copy regression; renaming a team must preserve grouping when its membership has not changed.
- 2026-09-22: The retained local league grows by several players per integration run (364 active by this date). Under a team preset every field deselection re-pairs the whole roster, so clearing the field one checkbox at a time timed out the throwdown journey on all four browsers. Clear the field under `individual_gross`, then switch presets. Two-person throwdowns cannot have an odd team count: the save contract rejects it, so every throwdown tee group has exactly four players.
- 2026-09-22: Never read child rows with `.in('parent_id', ids)` over a whole roster. At 366 players the URL exceeded the local gateway limit, Kong answered 414, and the players screen, which ignored that query's error, showed every handicap as "—". Embed the child rows in the parent select instead.
